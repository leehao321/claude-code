# 选购与线路比较

目录:1. 先问清需求 · 2. 查证流程 · 3. 比较维度 · 4. 买后验收 · 5. 输出格式

选购和"现在哪家线路更稳"属于**需要场景证据**的问题:不得凭记忆下结论,不得编造当前延迟数字。

## 1. 先问清需求

- 用途:科学上网 / 建站 / 跑业务 / 游戏 / 备份?
- 用户所在地区与运营商(电信/联通/移动,各占比)。
- 预算与付款周期;是否在意流媒体/AI 解锁、IP 纯净度。
- 能接受的折腾程度(要不要中转、要不要自己维护)。

## 2. 查证流程

1. 按 `community-research.md` 选板,至少查**两个**社区(商家当前质量争议时三个),中英文各一轨。
2. 找:近 3–6 个月的**用户实测**(含命令输出/截图),特别是晚高峰、不同运营商。
3. 区分 `[VENDOR]`(商家自述/促销)与独立用户测试,分开列。
4. 查商家的**使用条款(AUP)**、退款政策、历史封号/跑路/断网纠纷。
5. 促销站(LowEndBox、LowEndSpirit)只当线索,必须在讨论板二次确认。
6. 被拦、证据薄、互相矛盾:如实说明,标 `[UNKNOWN]` 或 `[CONTESTED]`,给"买后验收"方案降低风险。

## 3. 比较维度

| 维度 | 看什么 |
|---|---|
| 线路 | 三网回程 AS 路径(见 `nq-reading-guide.md`)、晚高峰丢包 |
| 去程/回程 | 回程影响下载,去程影响上传和游戏延迟,别混 |
| 带宽 | 峰值 vs 保底、是否限速、月流量与计费方式 |
| 虚拟化与规格 | KVM/LXC、CPU 单核、内存、硬盘 IO、超售口碑 |
| IP | 原生/广播、风险分、被墙历史、能否换 IP 及费用 |
| 条款 | 是否允许代理/转发/大流量、退款期 |
| 商家信誉 | 工单响应、续费涨价、稳定运营时长 |
| 总成本 | 首年价 vs 续费价、换 IP/加流量/备份等附加费 |

注意:价格与线路排名随时间变化很快,结论要带日期。

## 4. 买后验收

- **在退款期内**跑 NQ + 三网各一次闲时 + 一次晚高峰实测,数据对照宣传和社区口碑。
- 不达标 → 留证据(NQ 报告、mtr、测速)走退款/工单,别拖过退款期。
- 达标 → 建机器档案,进入调优流程。

## 5. 输出格式

```
## 选购比较(日期:<今天>)
| 项 | 方案 A | 方案 B |
|---|---|---|
| 线路/回程 | … | … |
| 价格(首年/续费) | … | … |
| 社区证据 | 站点·要点·日期 [标签] | … |
| 风险 | … | … |

结论:倾向 <X>,理由 …;不确定点 … ;建议买后验收 …
```

证据不足时,结论要写"倾向"而不是"推荐",并说明哪些点没查到。
