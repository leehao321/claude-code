# 怎么读 NQ 与配套测试

目录:1. NQ 报告各板块 · 2. 配套工具清单 · 3. 三网回程 AS 号速查 · 4. 常见"症状 → 病因"

脚本地址和参数会变。**执行前先核对官方 README 的当前命令**,下面只列工具名和用途,不保证命令永远有效。

## 1. NQ 报告各板块怎么看

| 板块 | 关注点 | 怎么用 |
|---|---|---|
| 基础信息 | CPU 型号/核数、内存、Swap、硬盘、虚拟化、内核 | 虚拟化决定调优空间;CPU 老旧或 steal 高,别指望重加密协议跑满 |
| CPU 跑分 | Geekbench / sysbench 单核 | 单核分低 → 代理吞吐上限低,优先轻量方案 |
| 磁盘 IO | fio 4K / 1M 读写 | 一般代理用途不吃 IO,但跑业务/日志重要;超低 IOPS 说明超售严重 |
| IP 质量 | 类型(原生/广播)、ASN、各库风险分、黑名单 | 风险高会影响 AI 服务、注册、风控;广播 IP 的地理位置可能与实际机房不符 |
| 流媒体/服务解锁 | Netflix、Disney+、YouTube Premium、ChatGPT 等 | 只说"当前时间点"的结果,解锁状态会变 |
| 邮件端口 | 25 出站是否开放 | 要发信才在意 |
| 三网延迟 | 电信/联通/移动到机房的 ping | 基线 RTT,与"回程"一起看 |
| 回程路由 | 各运营商回程 AS 路径 | 判断线路优劣的核心依据 |
| 网速 | 到多地的 iperf3/speedtest | 看跨洲、国内三网方向的实际速度 |

读报告时先找"异常":表中哪一板块明显劣于同价位常识(如 CPU 单核、IP 风险分、回程路由、网速),那就是这台机器的主要问题。

## 2. 配套工具清单(按需补测)

- **YABS**:硬件信息 + fio + 多地点 iperf3 + Geekbench。
- **IP 质量 / 网络质量脚本**(xykt 的 Check.Place 系列):IP 质量、网络质量、回程。以项目 README 为准。
- **NextTrace / besttrace / mtr**:路由追踪。`mtr -rwzbc 100 <目标>` 能给出每跳丢包和延迟,`-z` 显示 AS 号。
- **iperf3**:`-P` 是并行流数,`-R` 才切换方向。`iperf3 -c <服务端> -P 4` 测上传(客户端→服务端),`iperf3 -c <服务端> -P 4 -R` 测下载(服务端→客户端);单流与多流对比另用 `-P 1` 和 `-P 4`。
- **speedtest / speedtest-go**:对电信、联通、移动各选节点测速。节点要固定,前后对比才有意义。
- **长时间 ping**:`ping -c 300 -i 0.5 <目标>` 看丢包和抖动,至少覆盖一次晚高峰。
- **IP 信誉**:IPQS、Scamalytics、AbuseIPDB、ping0,多源交叉看,不要只信一个分数。

## 3. 三网回程 AS 号速查

以 AS 号为准,IP 前缀只作参考(商家和运营商都可能调整)。

**中国电信**
- AS4134(ChinaNet 163 骨干):普通线路,晚高峰常拥塞。
- AS4809(CN2):CN2 GT 只有国际段走 CN2(常见 59.43.x.x),入境后落回 163 骨干(202.97.x.x / AS4134),国内段仍是普通 163;CN2 GIA 从国际到国内终点全程走 CN2,59.43.x.x 之后不会再回到 202.97.x.x 骨干(末端落到目的运营商省网时可能出现少量 AS4134 接入跳,属正常)。**区分 GT 与 GIA 看 59.43 段之后是否又出现 202.97.x.x,不要只看有没有 59.43。**

**中国联通**
- AS4837(CU169):普通线路。
- AS9929(联通 A 网/精品网):优质线路,常见 218.105.x.x 等段。
- AS10099(联通国际 CUG):部分 HK/SG 线路会出现。

**中国移动**
- AS9808(CMNET 国内骨干)。
- AS58453(CMI 国际出口):普通国际线路。
- AS58807(CMIN2):移动的优质国际线路。

判断口径:
- 三网路径里出现 4809 GIA / 9929 / CMIN2 → 优质回程,通常直连即可。
- 全是 4134 / 4837 / 58453 → 普通线路,是否可用看晚高峰实测,不要只看闲时。
- 某一网走绕路(如联通/移动绕欧美)→ 对应运营商用户体验差,考虑换入口或中转。

注意:**回程**(VPS → 国内)决定下载体验;**去程**(国内 → VPS)决定上传和游戏类延迟。NQ 主要给回程,去程需要在国内侧测或让用户用国内机器 traceroute。

## 4. 常见"症状 → 病因"

| 症状 | 优先怀疑 | 验证办法 |
|---|---|---|
| 闲时快、晚高峰慢 | 线路拥塞(普通线路) | 多时段 mtr,看丢包是否出现在跨境跳 |
| 延迟比同城机房高很多 | 绕路 | NextTrace 看是否经欧美/第三国 |
| 单线程慢、多线程快 | 缓冲区/BDP、丢包下的单流退化 | iperf3 `-P 1` 与 `-P 4` 对比 |
| 速度被锁在固定值 | 商家限速/端口 QoS | 换端口、换协议对比,iperf3 直测 |
| 小包卡、大包通 | MTU/MSS 问题 | `ping -M do -s <大小>` 探测路径 MTU |
| CPU 打满带宽上不去 | 加密吞吐受限 | `top` 看单核占用,换轻量协议或升配 |
| IP 偶发连不上 | IP 被封/被限速 | 多地同时 ping/tcping 对比,必要时换 IP |
